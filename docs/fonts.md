# Fonts Required

Place these `.ttf` files in this directory (`app/src/main/res/font/`):

- `inter_regular.ttf`     — from https://rsms.me/inter/
- `inter_medium.ttf`
- `inter_semibold.ttf`
- `inter_bold.ttf`
- `jetbrains_mono_regular.ttf` — from https://www.jetbrains.com/lp/mono/
- `jetbrains_mono_medium.ttf`

Filenames must be lowercase and use underscores (Android resource naming).

These files are referenced by `RaycastTheme.kt` via `R.font.*`.
